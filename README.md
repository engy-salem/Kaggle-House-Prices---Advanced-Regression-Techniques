# House Price Prediction

## Project Overview
This project predicts house sale prices using machine learning regression techniques and the Kaggle House Prices dataset.

## Workflow
- Data exploration and analysis
- Handling missing values
- Feature engineering
- Categorical feature encoding
- Training a Gradient Boosting Regressor
- Model evaluation using RMSLE
- Generating predictions for the Kaggle test dataset

## Model
Gradient Boosting Regressor

## Evaluation Metric
Root Mean Squared Logarithmic Error (RMSLE)

## Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
